# 独立レビュー依頼・実行境界

対象はこのPRのv0.2.0設計、合成判定モデル、fixture/oracle、互換性と影響調査。原物保全やStage 1実運用の受入ではない。

重点: Level誤分類と過剰BLOCKED、L1に不要保存承認を要求しないこと、既知FAILをUNKNOWNで隠さないこと、SOLO/STRICTの独立性、範囲承認の不正再利用、原物再生成と旧結果改変の拒否、bundle目的の検査維持、合成permit=false、旧AT/SM結果の分離。

作成担当とoracle/review担当は別AI agent。後者は初期44のoracleを実装閲覧前に固定し、レビューで追加した境界は各初回実行前に期待固定する。同一提供基盤、共有workspace、継承履歴・同一アカウントの限界を開示する。別人・別資格情報による第三者監査と称さない。

P1/P2/P3、再現入力、期待/実際、修正前後hashを追記で記録。同じ反例で再実行。提出後は固定HEADから別取得先へ読み戻し、レビューした内容と一致を確認する。Stage 1・他repo適用・採用・mergeは別ゲート。
