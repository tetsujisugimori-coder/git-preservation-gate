# 保存承認再利用・原物救済案

## 承認契約
案件限定approvalと範囲approvalを区別する。再利用時は対象/データ分類、許可先、主体/操作範囲、アクセス権、保持期間、削除/移動条件、有効期間を照合。全て範囲内なら成果物ごとの新承認票は原則不要。案件限定を全repoへ拡張しない。期限切れ・転送先変更・機密分類変更・対象外操作は停止。L3は個別承認を要す。

承認の存在と実効ACL/容量/書込・再取得可否/保持条件を別欄にする。承認された保持期限はサービスがその期間保持できる証明ではない。保存先の一般的な無期限存続はUNKNOWNのままでよく、案件に必要な期限・アクセス要件を別途確認する。既承認の通常保存先で毎回新しい人格・accountを要求しない。秘密・非公開locator・承認原本は公開GitHubへ載せない。

## 保全救済
1. 今ある原物を変更/削除/移動/上書きしない。原物識別と測定結果を先に記録。
2. 元環境消失の危険がある場合、既承認の対象/保存先/操作範囲と機密/ACL条件を照合。
3. 許可範囲内の新規領域へ緊急コピーしreceiptを記録。無承認先・機密疑い・ACL不足なら転送しない。
4. 保存状態と未完の再取得/内容検査を別票で管理。監査者待ちだけで許可済み救済コピーを止めない。
5. 救済は正式監査・受入・マージPASSではない。未確認をUNKNOWN、未実施をNOT_TESTEDとする。原物不在を再生成物で埋めない。

## 過去判定の再審査
|旧阻害|v0.2採用後の扱い|
|---|---|
|原物喪失/所在UNKNOWN|停止維持。所在限定調査または欠損受容の別審査|
|破損/不一致|FAIL維持。修復物は別版、元失敗を保持|
|保存先不達/権限不足|安全な読取は可、保存は到達/承認成立まで停止|
|承認票重複|既存範囲approvalの適合を確認できれば手続き再審査可能|
|別担当者不在|Level/監査契約と版採用を確認してSOLOの技術監査を新attemptで審査可能|
|安全/機密リスク|必要な停止を維持。レベル引下げで解除しない|

変更票は旧判定・旧規約commit/対象・新規約commit・新証拠・新判定・理由・責任者を追記。採用だけで旧結果をPASSにしない。制度変更の承認、案件への適用承認、実検査結果は別物。
